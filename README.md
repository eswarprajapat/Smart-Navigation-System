# 🌍 Smart Navigation Map

link of the project : https://smart-navigation-system-2.onrender.com/

A lightweight, real-time GPS navigation and spatial mapping web application built for my Final Year Project. 

Unlike static maps, this project features spatial awareness, calculating the physical distance to upcoming turns and triggering real-time actions.

## ✨ Features
* 📍 **Live GPS Tracking:** Follows your location as you drive.
* 🗣️ **Voice Navigation:** Reads turn-by-turn directions out loud.
* 🚗 **Presentation Simulator:** A built-in virtual car to demonstrate driving routes without leaving your desk.
* 🚶 **Multi-Modal:** Calculates separate routes for cars, bikes, and walking.
* ⛽ **Quick POI Scanner:** Instantly finds nearby petrol stations, hospitals, and parking.

## 🛠️ Tech Stack
* **Frontend:** HTML, CSS, JavaScript, Leaflet.js
* **Backend:** Python, Flask
* **APIs:** OpenRouteService, OpenStreetMap (Nominatim & Overpass)
* **Hosting:** Render

## 💻 Run it Locally
1. Clone the repository.
2. Install the requirements: `pip install -r requirements.txt`
3. Add your OpenRouteService API key in `index.html`.
4. Run the server: `python app.py`
